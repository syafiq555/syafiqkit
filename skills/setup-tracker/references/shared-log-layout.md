# Shared log layout

Copy an existing tracker's layout when the same team already works in one. Read this when the people who will answer already use another tracker, or when a tracker's owner runs one on a running-log shape.

Copy its column names, status words and reply shape (a "Remarks / Updates" cell of dated "Name dd/MM:" lines, say), and add only what it lacks and this sheet needs. A layout they already know needs no learning, and the same holds when bringing an existing tracker up to date: an owner who runs another tracker on the running-log shape wants that shape here too, not this skill's History script (16/11/2026: "i dont want the script like that", the second owner refusal). In a shared log cell, each person's lines can carry their own text colour with the name in bold (`"person_colours": {"Syafiq": "38761D"}` colours every "Name dd/MM:" line, and the lines under it, in Latest update and History); leave blue for the client, who usually types in it. Two gsheets tools then need the colour too: `cell_append_line` writes black unless given it (and has no bold, so a name added by hand stays plain), and `cells_awaiting_reply` reads only black and uncoloured text as yours unless the colour is in its `mine`, so without it every row reads as waiting on you. Record the colour where the project's tracker notes live. `"font": "Arial"` sets the font of the tabs it builds (and the file's default, on a new file), for readers who find Google's default Roboto hard to read. One built on these defaults was rebuilt on the client's other sheet within days: "much more better to go with how they already used".
