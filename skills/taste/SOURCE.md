## Updating

`SKILL.md` is a restructured body, so do not re-copy it. Three-way update: diff `upstream/SKILL.upstream.md` (the pristine SKILL.md at the commit recorded above) against the new upstream `SKILL.md`; apply each upstream change to the matching passage of our `SKILL.md` or of the `references/` file the move list above names (section 2, section 3, section 5, run steps 4 to 6, the `data-move` bullets); then overwrite `upstream/SKILL.upstream.md` with the new upstream file. For the other files: re-copy `skills/taste-skill/` from the newer commit (keep `LICENSE`, `SOURCE.md`, `SKILL.md` and the new `references/` files above), delete files upstream no longer has, re-apply the patches listed above (unless upstream has fixed them), update the commit and date here, and note it in the plugin CHANGELOG. Check `SKILL.md`'s token count again (`tiktoken`, `cl100k_base`); restore the re-read note under the title if it passes 5,000. Test the Stop hook with `env -i PATH=/usr/bin:/bin sh -c '<command>'`.

## Requirements

The scripts need Node 22 or newer and an installed Chrome, Edge or Chromium (Playwright's own Chromium counts for the gate's checkers); some scripts also need network access (photographs, icons). ffmpeg is optional. Run them from the project's root so working files land in `.taste-skill/` there.
