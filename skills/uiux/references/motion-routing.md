# Motion work: which Emil skill takes it

Pass the motion task as the argument (bare, most of them only greet): `emil-design-eng` decides what moves and how; `emil-animate` builds one; `emil-choreograph` several together; `emil-gestures` drag, swipe, sheets; `emil-mobile-native` phone feel; `emil-remove-animations` slow or over-animated; `emil-review-animations` judges built motion, before calling screens done. Their values (curves, durations, the "should this animate at all" table) replace yours; `uiux` keeps layout, hierarchy and states.
