# Measured design incidents

The evidence behind three rules in `SKILL.md`. Read the one matching the rule you are applying.

## A one-word theme is a direction, not a costume

Measured 2026-09-14: four theme signifiers (hazard stripes, a rotated rubber stamp, rivets, a hatch texture) were rejected outright as "too much industrial". What was accepted inverted the register: off-white ground, the brand's own two colours as the only accent, one typeface with weight carrying hierarchy, the theme surviving as restraint. A brief's "no need to follow the existing palette" removes a constraint; it does not set the theme as the new goal. A page holding several separate things that exist only because of the theme word is the tell.

## A gap-list brief produces a crowded page

Measured 2026-09-05: a header that linked and explained every gap in the brief was rejected as "very crowded, lesser things to focus". The fix was fewer elements: relations folded into a muted line, the zero-count column hidden.

## A control belongs in the same container as what it changes

Measured 2026-09-29: a month-by-month table that re-rendered a statement card above it was first given a picker chip, and the user called that "separated with some hacky way". It was accepted once each month row opened its own statement in place.

## A fabricated logo reads as a finished decision

Placeholders that ship silently: initials in a circle, an emoji, a generic icon-set mark, an invented SVG that merely looks brand-shaped. Where no real mark is available, leave the space empty or set the product name as text, and say the logo is missing; that is a question for whoever owns the brand.
