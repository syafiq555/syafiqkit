# Casual Malay defaults

Patterns from a colleague's real WhatsApp messages to another colleague (reported 05/11/2026). They are one sender's habits, so treat them as a starting point for a casual Malay draft, not a norm. Spelling and pronouns vary from person to person (`x` or `tak`, `aku` or `saya`), so the sender's own sent messages always win over this list.

## Shape {#shape}

- All lowercase, almost no punctuation, no emoji.
- Answer first ("mmg issue", "x jadi issue kot"), then the reason after `sbb`.
- No greeting beyond replying to theirs (`wsalam`), no closing line.
- Several short bubbles, one point each. A later bubble adds a follow-up ("untuk X tu kan.").
- Proof in brackets as names, e.g. "(db1, db2, db3)", never links or tables.

## Spelling {#spelling}

| Written | Means |
|---|---|
| `aku` | common to colleagues, `saya` to clients; take it from the thread or ask (SKILL.md, Language, the pronouns paragraph) |
| `x` | tak |
| `x da` / `x de` | tak ada |
| `mmg` | memang |
| `sbb` | sebab |
| `dlm` | dalam |
| `dgn` | dengan |
| `sngt` | sangat |
| `diorg` | dia orang |
| `tp` | tapi |
| `utk` | untuk |
| `dua2`, `apa2` | repetition with a 2 |

`yang` stays spelled out in full.

## Particles and connectors {#particles}

- `kot` softens a claim; `je`, `kan`, `pun`, `pulak` carry tone.
- `tu` / `ni` after a noun ("db ni", "detective tu").
- `so` and `tapi` join clauses.
- "X punya Y" for possessive ("prepayment punya db").

## Code-switching {#code-switching}

Tech terms stay English and lowercase: issue, standard rds, dashboard, region, cost.

## Example accepted as written {#example}

A reply to a colleague asking whether two AWS services were available in the Malaysia region. The recipient's name is made up.

```
wsalam ali, dah check

detective tu mmg x da kat my. yang sg punya pun x boleh cover my sbb detective ni per region

tapi x jadi masalah sngt kot. detective tu cuma tempat search/investigate je, yang detect guardduty dgn securityhub. dua2 ni ada kat my

rds custom pulak x jadi issue sbb db dia (db1, db2, db3) standard rds. standard rds sql server ada kat my
```

Four bubbles: the greeting answered with the headline, then one point per bubble, each answer first with the reason after `sbb`, and no closing line.
